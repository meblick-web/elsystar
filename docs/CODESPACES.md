# ELSYSTAR in GitHub Codespaces

The repository includes a ready-to-use cloud development environment.

When a Codespace is created from `main`, GitHub will:

1. Start a Node.js 22 development container.
2. Start PostgreSQL 16 in a separate service container.
3. Persist PostgreSQL data in the `postgres-data` Docker volume.
4. Run `npm install`.
5. Generate Prisma Client.
6. Apply the development database schema with `npm run db:push`.
7. Start the public site on port `6300`.
8. Start the admin app on port `6301`.
9. Forward both ports automatically.

Development-only bootstrap administrator:

- Email: `admin@elsystar.local`
- Password: `codespaces-preview-only`

These credentials are only for the isolated Codespaces development environment and must never be reused for production.

Runtime logs:

- `.codespaces/logs/web.log`
- `.codespaces/logs/admin.log`

The forwarded URL format is generated by GitHub Codespaces and looks like:

- `https://<codespace-name>-6300.app.github.dev`
- `https://<codespace-name>-6301.app.github.dev`

Codespaces ports are private by default. Public visibility, if required for sharing with unauthenticated users, is a runtime Codespaces setting and is not treated as a production hosting configuration.
