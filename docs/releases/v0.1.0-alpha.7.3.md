# v0.1.0-alpha.7.3 — Exact Codespaces Origin Hotfix

## Problem

Admin login through GitHub Codespaces continued to fail with `Invalid Server Actions request` even after allowing `*.app.github.dev`.

Next.js rejects a Server Action when the browser `Origin` does not match `Host`/`X-Forwarded-Host` and the origin is not accepted by `serverActions.allowedOrigins`.

## Fix

Both Next.js applications now calculate the exact forwarded Codespaces hostname at startup from:

- `CODESPACE_NAME`
- `GITHUB_CODESPACES_PORT_FORWARDING_DOMAIN`

Admin example:

`<codespace>-6301.app.github.dev`

Public web example:

`<codespace>-6300.app.github.dev`

The exact hostname is inserted into both `allowedDevOrigins` and `experimental.serverActions.allowedOrigins`. Wildcard patterns remain only as fallback compatibility entries.

This avoids relying on wildcard matching for the active Codespace and covers admin login plus all other Server Actions used by the public and admin applications.
