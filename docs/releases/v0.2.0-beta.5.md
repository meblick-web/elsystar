# v0.2.0-beta.5 — Content, Media & Catalog Completion

## Цель

Перевести ELSYSTAR из демонстрационно-заполненного сайта в содержательно пригодный корпоративный каталог: использовать проверенные публичные сведения ELSYSTAR, расширить продукцию и решения, перенести открытые документы/ПО и отделить подтверждённые данные от временного или требующего ручной проверки контента.

## Реализовано

### Каталог продукции

- расширена структура категорий: дорожные контроллеры, модули и комплектующие, инженерные пульты, периферийное оборудование и заготовка для подтверждённых совместимых светофоров;
- УК-4.1М и УК-2.5 дополнены опубликованными техническими параметрами;
- добавлены опубликованные варианты комплектации УК-4.1 и УК-2.5 без переноса цен;
- добавлены отдельные CMS-позиции для блоков УК-4.1, шкафа, тумбы, инженерного пульта, ТВП и ВПУ;
- настроены product relations между контроллерами и совместимыми/комплектующими позициями;
- новые сущности получают базовые EN-названия и краткие описания без создания второго каталога.

### Решения и ПО

- существующие страницы управления перекрёстками, «Мегаполиса» и модернизации получили полные описания;
- добавлены отдельные направления координированного управления / «Зелёной волны», адаптивного управления и диспетчеризации/мониторинга;
- содержание основано на опубликованной архитектуре и функциях АСУДТ «Мегаполис».

### Медиа

- точечные alpha9.2 stock-изображения УК-4.1М и УК-2.5 заменяются на изображения, опубликованные на официальном сайте ELSYSTAR;
- stock-изображения ключевых решений заменяются только когда URL всё ещё равен известному bootstrap-значению;
- пользовательские/редакторские изображения bootstrap никогда не перезаписывает;
- до подключения production media storage изображения остаются внешними URL и должны быть перенесены в собственное хранилище на этапе production.

### Документация и Software Center

В CMS импортируются публично доступные legacy-материалы:

- инструкция УК-4.1М;
- инструкция и техническое описание УК-2.5;
- русское и английское руководство SVP;
- FlashProg;
- SVPWin;
- буклет УК-4.1М / УК-2.5;
- опубликованный сертификат УК-4.1 как архивный материал, требующий отдельной проверки актуальности перед production.

Версия/год хранятся как version label. Точные даты публикации не выдумываются.

### Content QA

`/content-qa` теперь различает критичные пробелы и предупреждения и дополнительно проверяет:

- комплектации дорожных контроллеров;
- связи с модулями/периферией;
- наличие серий документов;
- временные Unsplash URL;
- наличие текущей публичной версии документа;
- HTTPS для файлов;
- EN-покрытие опубликованных сущностей;
- подтверждённость корпоративных реквизитов без требования выдумывать отсутствующие данные.

### Provenance

Добавлен `docs/CONTENT-SOURCES.md` с источниками и правилами миграции. Beta5 bootstrap пишет AuditLog marker `content.bootstrap.beta5 / verified-catalog-content-v1` и после первого успешного применения не восстанавливает удалённые редактором сущности.

## Источники

Для beta.5 использовались только открытые официальные страницы текущего ELSYSTAR: главная, `production.html`, `software.html`, `support.html` и `price.html`. Страница `price.html` используется только как источник названий и состава комплектаций — цены не импортируются.

## Не сделано намеренно

- не добавлены неподтверждённые адрес, ИНН, КПП или ОГРН;
- не созданы фиктивные клиенты или новые «реальные» проекты;
- демо-кейсы остаются явно демонстрационными;
- не утверждается актуальность legacy-сертификатов и программ без ручной проверки;
- не выбрано production media storage/hosting.

## Codespaces

После обновления `start-preview.sh` один раз применит beta5 content bootstrap и выведет:

```text
[ELSYSTAR] beta5 verified catalog, media and documentation synchronized.
```

Повторные запуски не перезаписывают редакторский контент.
