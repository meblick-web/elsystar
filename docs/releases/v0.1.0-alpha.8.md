## Codespaces Server Actions normalization

Existing CMS screens rely on Server Actions. GitHub Codespaces adds a reverse-proxy layer that can expose a different forwarded host to Next.js.

Alpha.8 adds a local preview proxy:

- Next.js runs internally on `16300` / `16301`;
- preview proxy publishes `6300` / `6301`;
- requests from the exact current Codespaces origin receive a normalized `Host` / `X-Forwarded-Host` before reaching Next.js;
- WebSocket upgrade proxying is included for development HMR;
- this is intended to make all existing Server Action forms work through Codespaces, not only login.

The normal HTTP POST login path from alpha.7.4 is retained.
