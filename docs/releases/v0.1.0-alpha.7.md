# v0.1.0-alpha.7 — Documentation & Software Center

## Document series

Documentation is now modelled as a stable series plus individual file versions.

Examples:

- `Руководство УК-4.1М / RU`
- `Сертификат УК-4.1М / RU`
- `ПО АСУДТ Мегаполис / RU`
- `Прошивка контроллера / RU`

Each series has a stable slug, type, language, optional product relation and ordered versions.

## Version history

Each version can store:

- version number;
- file URL and filename;
- MIME type and file size;
- release date;
- public/draft state;
- current-version flag;
- description;
- release notes;
- SHA-256 checksum.

Previous versions remain available as an archive instead of being overwritten.

## Admin UX

- `/documents` — search/filter and series management.
- `/documents/[id]` — series editor and full version history.
- filters by type, product, language and text query.
- current version switching.
- publication control for every version.
- audit log entries for series and version operations.
- roles `ADMIN`, `EDITOR` and `SUPPORT` may manage documentation.

## Public UX

- `/support` shows one card per series with its current public version.
- search and filters by type, product and language.
- `/support/[slug]` shows the current release, release notes, SHA-256 and previous public versions.
- product pages show current document versions instead of the full archive.
- legacy standalone documents from earlier alpha versions remain readable and manageable.

## Codespaces

Codespaces preview startup now runs Prisma Client generation and `db:push` before starting web/admin, so schema changes from new releases are applied automatically after updating the repository.
