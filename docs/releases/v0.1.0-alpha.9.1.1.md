# v0.1.0-alpha.9.1.1 — Codespaces Port Cleanup

Infrastructure hotfix on top of `v0.1.0-alpha.9.1`.

## Changes

- Internal Next.js ports `16300` and `16301` are explicitly marked with `onAutoForward: ignore` in the Codespaces configuration.
- User-facing preview ports remain `6300` for the public site and `6301` for admin.
- The Codespaces reverse proxy now normalizes `Host`, `X-Forwarded-Host`, `X-Forwarded-Proto` and `X-Forwarded-Port` for every HTTP and WebSocket request instead of only requests that contain a matching `Origin` header.
- No application business logic, database schema or public design was changed.
