# v0.1.0-alpha.9.1.1 — Codespaces Port Cleanup

Infrastructure hotfix on top of `v0.1.0-alpha.9.1`.

## Changes

- Internal Next.js ports `16300` and `16301` are explicitly marked with `onAutoForward: ignore`.
- User-facing preview ports remain `6300` for the public site and `6301` for admin.
- Codespaces proxy now normalizes `Host`, `X-Forwarded-Host`, `X-Forwarded-Proto` and `X-Forwarded-Port` for all HTTP and WebSocket traffic.
- No application business logic, database schema or public design changed.
