# v0.1.0-alpha.4 — Solutions, Projects & Homepage CMS

## Public site

- Homepage content is now read from `HomepageContent` with safe fallback values.
- Featured solutions drive the directions section.
- A `PLATFORM` solution can represent АСУДТ «Мегаполис» without hard-coding a separate content system.
- Added `/solutions` and `/solutions/[slug]`.
- Added `/projects` and `/projects/[slug]`.
- Featured projects can appear on the homepage.
- Public app is forced dynamic so CMS changes become visible without rebuilding the application.

## Admin

- Homepage editor for hero, CTA, section headings and support copy.
- Solutions manager with `SOLUTION / PLATFORM`, publication state, featured state, ordering and SEO fields.
- Projects manager with geography, year, task, implementation, result and SEO fields.
- Projects can be related to multiple products and solutions.
- Dashboard navigation exposes Homepage, Solutions and Projects CMS modules.
- Public preview links use `NEXT_PUBLIC_SITE_URL` instead of opening inside the admin application.

## Data model

- `HomepageContent`
- `Solution`
- `Project`
- `ContentStatus`
- `SolutionType`
- many-to-many Project ↔ Product
- many-to-many Project ↔ Solution

## Design rule

ELSYSTAR intentionally does not use a universal drag-and-drop page builder. Editors manage typed content entities while the public layout remains controlled by the product design system.
