# v0.2.0-beta.2 — SEO, Migration & Internet Visibility

## Цель

Подготовить ELSYSTAR к безопасному переносу `elsystar.com`, индексации Google/Yandex и сохранению поисковых сигналов старого сайта без случайной индексации Codespaces/demo-контента.

## Реализовано

### Canonical / metadata
- единый helper production site origin;
- автоматический canonical для публичных маршрутов;
- DB `SeoRoute` остаётся приоритетным override;
- OpenGraph + Twitter metadata;
- Google/Yandex verification meta через environment;
- улучшенные title/description основных разделов;
- entity metadata для товаров, решений, проектов и серий документации.

### Search crawler controls
- public `/robots.txt`;
- public `/sitemap.xml`;
- preview/Codespaces закрыты от индексации по умолчанию;
- индексация включается только `SEO_INDEXING_ENABLED=true` на не-preview hostname;
- admin всегда `noindex,nofollow` и `Disallow: /`.

### Sitemap
- основные публичные маршруты;
- опубликованные товары;
- опубликованные решения;
- опубликованные реальные проекты;
- публичные текущие серии документации;
- `SeoRoute.indexable=false` исключается;
- demo-проекты исключаются.

### Structured data
- Organization + WebSite;
- Product без фиктивных Offer/price/review;
- Service для решений;
- Article только для реальных проектов;
- demo cases не получают индексируемый Article schema.

### Legacy migration
Bootstrap добавляет управляемые 301:
- `/index.html` → `/`;
- `/production.html` → `/production`;
- `/support.html` → `/support`;
- `/software.html` → `/solutions/megapolis`;
- `/price.html` → `/products`.

Правила сохраняются в существующем `RedirectRule`, отображаются и редактируются в админке.

### SEO Admin
- readiness dashboard;
- canonical host;
- indexing ON/OFF;
- количество SEO routes и redirects;
- status verification tokens;
- ссылки на robots/sitemap;
- validation canonical URL;
- redirects ограничены внутренними путями и не могут вести сами в себя.

### Performance / QA
- глобальный public `force-dynamic` заменён на ISR/revalidate 300 секунд;
- CMS actions продолжают использовать `revalidatePath`;
- response compression явно включён;
- `X-Powered-By` отключён;
- `seo:check`;
- production SEO preflight;
- hard-coded internal link check;
- CI валидирует SEO/bootstrap scripts.

## Важные ограничения

- Включение индексации не выполняется в Codespaces.
- Search Console / Yandex Webmaster подключаются после появления production domain/HTTPS.
- Core Web Vitals измеряются после production deployment, а не по dev server.
- SEO не гарантирует позиции или сроки попадания страниц в индекс.
