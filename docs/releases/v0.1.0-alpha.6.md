# v0.1.0-alpha.6 — Product Catalog Completion

## Catalog structure

- Hierarchical product categories with parent/child relations.
- Category manager in admin with usage-safe deletion.
- Public category filters on `/products`.

## Product content

- Structured technical specifications.
- Product advantages/features.
- Product configurations with optional SKU/code.
- Ordered product image gallery with a single primary image.
- Product ↔ Solution and Product ↔ Project relations.
- Product relations: compatible, accessory, alternative and related.
- Existing documentation remains linked through Documentation Center.

## Product editor

The product editor now manages:

- main identity, category, publication state and sorting;
- description and SEO;
- related solutions/projects;
- images and main image;
- features;
- configurations;
- specifications;
- compatibility/related products;
- linked documents.

## Public product UX

- Category navigation and filtering.
- Real product images when available, with controlled fallback visuals.
- Product gallery.
- Advantages and configurations.
- Related solutions and deployments.
- Related/compatible products.
- Product documentation and product-aware commercial enquiry form.

## Controller bootstrap

Admin catalog includes a non-destructive bootstrap action for verified baseline models:

- УК-4.1М
- УК-2.5

The action creates missing models and the `Дорожные контроллеры` category only. Existing product records are never overwritten.

## Data model

Added:

- `ProductFeature`
- `ProductConfiguration`
- `ProductRelation`
- `ProductRelationType`
- category hierarchy
- Product ↔ Solution relation
- `MediaAsset.isPrimary`
