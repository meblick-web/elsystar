# v0.2.0-beta.4 — RU/EN Localization & Content Completion

## Цель

Заменить декоративный `RU / EN` на настоящую двухъязычную публичную структуру без дублирования каталога и без смешивания непереведённого контента в поисковом индексе.

## Реализовано

### Public locales
- русский остаётся основным на `/...`;
- английский контур доступен на `/en/...`;
- поддержаны главная, каталог и карточки продуктов, решения, проекты, документация, компания, производство, контакты и FAQ;
- один набор product/solution/project/document entities используется обеими локалями;
- глобальный переключатель RU / EN сохраняет текущий путь и query string;
- форма коммерческого запроса локализована на английский и отправляет данные в тот же защищённый lead pipeline.

### Translation CMS
- новая модель `ContentTranslation`;
- отдельный editor/admin route `/localization`;
- поиск и фильтр переводов;
- inline edit, delete и manual upsert;
- audit log для translation create/update/delete;
- доступ только `ADMIN` / `EDITOR`.

### Initial English content
- английские значения для главной и корпоративных разделов;
- UK-4.1M и UK-2.5;
- базовые категории, характеристики и преимущества;
- Megapolis и основные решения;
- текущие демонстрационные проекты с явной demo-маркировкой;
- FAQ;
- bootstrap добавляет только отсутствующие строки и не перезаписывает редакторские изменения.

### International SEO
- canonical для `/en/...`;
- RU/EN/x-default hreflang;
- English OpenGraph metadata;
- English dynamic entities попадают в sitemap только при наличии явного перевода primary title/name;
- demo project detail остаётся `noindex`;
- preview/Codespaces по-прежнему полностью закрыт от поисковой индексации.

### Operations / QA
- localization bootstrap включён в Codespaces startup;
- localization bootstrap включён в guarded clean-production DB initialization;
- production smoke теперь проверяет RU и EN routes;
- release preflight требует localization layer;
- CI проверяет bootstrap script syntax.

## Архитектурное правило

Русская CMS-запись остаётся source of truth для идентичности сущности, публикации, связей, media и технических данных. `ContentTranslation` хранит только локализуемые строки. Таким образом перевод не создаёт второй продукт или второй проект.

## Ограничения

- автоматически переводить новый пользовательский контент система не пытается;
- редактор должен добавить/проверить EN-строки через `/localization`;
- историческая Prisma migration chain всё ещё не создана; новый `ContentTranslation` в текущей development DB создаётся через guarded development schema sync, а первый production deployment рассчитан на чистую БД;
- выбор hosting provider и включение production indexing не входят в beta.4.
