# v0.1.0-alpha.9.2 — CMS Source of Truth & Codespaces Cleanup

## Цель

Устранить расхождение между публичным сайтом и административной панелью: редактируемый контент не должен существовать только как fallback внутри React/TypeScript-кода.

## CMS source of truth

При первом запуске после обновления выполняется однократный безопасный bootstrap текущего видимого контента в PostgreSQL:

- главная страница;
- корпоративный контент;
- компетенции;
- FAQ;
- категория «Дорожные контроллеры»;
- УК-4.1М;
- УК-2.5;
- характеристики и преимущества базовых товаров;
- базовые изображения товаров;
- решения «Управление перекрёстками», АСУДТ «Мегаполис», «Модернизация объектов»;
- четыре явно обозначенных демонстрационных проекта.

Bootstrap:

- не перезаписывает существующие записи;
- не дублирует уже заполненные характеристики/преимущества/изображения;
- выполняется в транзакции;
- после успеха записывает постоянный marker в `AuditLog`;
- при последующих стартах ничего не импортирует повторно;
- если пользователь позднее изменит или удалит запись, bootstrap её не восстановит.

При подключённой БД публичные списки товаров, решений, проектов и FAQ теперь используют состояние CMS как источник истины. Code fallback остаётся только аварийным режимом для запуска без PostgreSQL или при ошибке чтения БД.

## Demo projects

Демонстрационные кейсы теперь являются обычными редактируемыми сущностями `Project` в CMS. Задача, решение, результат, город, регион, год, обложка и модельные KPI содержатся в полях проекта. Публичный слой определяет demo-статус по `demo-*` slug / названию и формирует компактные KPI из текста результата.

## Codespaces

- `16300` и `16301` помечены как внутренние порты и больше не должны автоматически предлагаться пользователю;
- пользовательские preview-порты остаются `6300` и `6301`;
- proxy всегда нормализует `Host`, `X-Forwarded-Host`, `X-Forwarded-Proto` и `X-Forwarded-Port` для обычных HTTP-запросов и WebSocket/HMR;
- startup автоматически запускает bootstrap контента после безопасного `db:push`.

## Без изменения бизнес-данных

Декоративные технические фоновые схемы, сетки дорог и другие элементы design system остаются частью CSS и не считаются CMS-контентом.
