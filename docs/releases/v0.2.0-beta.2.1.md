# v0.2.0-beta.2.1 — Public Codespaces Preview

## Цель

Сделать публичный сайт Codespaces доступным с любого устройства по preview URL без входа в GitHub, сохранив административный контур приватным.

## Изменения

- после запуска Codespace порт `6300` автоматически переводится в `public`;
- порт `6301` административной панели принудительно остаётся `private`;
- автоматизация использует официальный `gh codespace ports visibility`;
- если GitHub CLI недоступен, токен не разрешает изменение или политика организации запрещает public ports, старт сайта не падает: выводится инструкция переключить `6300` вручную через PORTS;
- поисковая индексация Codespaces по-прежнему выключена (`SEO_INDEXING_ENABLED=false`), поэтому публичная preview-ссылка предназначена для просмотра, а не для поисковой выдачи.

## Безопасность

Public preview означает, что любой человек, знающий URL порта `6300`, может открыть сайт. Admin `6301` не публикуется.
