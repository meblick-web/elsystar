# v0.1.0-alpha.9.3 — Content & Visual QA

Последний alpha-этап перед security/operations beta.

## CMS как источник видимого контента

- расширен `HomepageContent`: теперь в админке редактируются trust-strip, заголовок продукции, support eyebrow и блок коммерческого запроса;
- публичная главная читает эти значения из CMS;
- проекты получили явный `isDemo` и три редактируемых KPI-показателя;
- удалён эвристический разбор KPI из текста результата проекта;
- demo-проекты продолжают иметь явную публичную маркировку;
- отдельный одноразовый bootstrap переносит KPI существующих demo-проектов в новые поля и ставит audit marker.

## Content QA Center

Добавлена административная страница `/content-qa`:

- опубликованные товары без полного описания, изображения, характеристик или преимуществ;
- решения без полного описания или изображения;
- проекты без обложки, задачи, решения, результата или KPI;
- серии документов без версий;
- неполные корпоративные данные и реквизиты;
- ручной checklist для desktop/mobile QA.

## Visual QA

- технические placeholder-состояния для сущностей без изображения;
- выровнены project cards и empty states;
- ограничена высота длинных описаний в карточках;
- улучшены mobile-состояния QA-блоков;
- декоративные дорожные схемы остаются частью design system и не смешиваются с редакторским контентом.

## Codespaces / data migration

После `db:push` startup запускает:

1. существующий visible-content bootstrap;
2. одноразовую `alpha9.3` CMS QA migration;
3. web/admin preview.

Оба bootstrap-процесса идемпотентны через `AuditLog` markers.
