# v0.1.0-alpha.3 — Leads, Documentation & Media Center

## Public site

- Commercial enquiry form on the homepage and product pages.
- Product-aware lead attribution.
- UTM/source path capture.
- Public documentation center at `/support`.
- Public documents are shown only when both `isPublic` and `publishedAt` are set.

## Admin

- Leads inbox with workflow statuses.
- Documentation management with type, version, product relation and publication state.
- Provider-neutral media library with URL/storage metadata.
- Dashboard links to the new operational modules.

## Data model

- `MediaAsset` model and `MediaType` enum.
- `Lead` is related to `Product`.
- Documents include public/private state, MIME type and file size metadata.

## Storage decision

Binary upload is intentionally not tied to Vercel, S3 or another provider yet. The content model stores provider-neutral URLs and storage keys so a storage adapter can be selected later without redesigning the CMS.

## Validation

Required pipeline: production dependency audit, Prisma Client generation, TypeScript, public production build and admin production build.
