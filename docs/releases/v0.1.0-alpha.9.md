# v0.1.0-alpha.9 — Design & Responsive Polish

## Goal

Bring the public site and admin panel to one coherent visual system without changing product/business logic.

## Public site

- unified light industrial B2B design tokens;
- calmer typography, spacing, borders and surface hierarchy;
- sticky responsive header;
- mobile navigation remains available as a horizontal scrollable menu instead of disappearing;
- homepage hero simplified: decorative dashboard removed, technical controller visual retained;
- cards across products, solutions, projects, documentation and corporate sections use consistent geometry and interaction states;
- improved catalogue cards, product detail layouts, filters, documentation series, corporate pages and contact blocks;
- consistent buttons, CTA, hover and keyboard focus states;
- responsive breakpoints refined for desktop, tablet, phone and narrow phone widths;
- `prefers-reduced-motion` support;
- dedicated loading, error and 404 states.

## Admin panel

- unified admin surfaces, controls, tables, cards and forms;
- more compact, readable desktop sidebar;
- tablet/mobile navigation no longer disappears: it becomes a sticky horizontal navigation strip;
- responsive form grids, media cards, relation cards, tables and action groups;
- improved focus, hover, disabled, success, warning and danger states;
- dedicated loading, error and 404 states.

## Compatibility

- no Prisma schema changes;
- no business-logic changes;
- Codespaces preview and PostgreSQL workflow remain unchanged;
- design is implemented as final alpha-level style layers over previous functional releases so existing screens remain compatible.
