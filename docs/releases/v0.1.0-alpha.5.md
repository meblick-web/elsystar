# v0.1.0-alpha.5 — Analytics, Users, Audit & SEO Operations

## Analytics

- Dedicated `/analytics` admin dashboard.
- 30-day visitors, sessions, page views, product views, downloads, leads, CTA clicks and conversion rate.
- Source attribution, device split and top pages/products.
- Visitor and 30-minute session cookies.
- UTM source/medium/campaign capture in event metadata.

## Users & roles

- Database-backed administrator accounts.
- Roles: `ADMIN`, `EDITOR`, `SUPPORT`, `ANALYST`.
- Passwords are stored as salted scrypt hashes.
- Bootstrap `.env` credentials remain as recovery/first-login access.
- User creation, activation, role changes and password reset are audit logged.

## Audit

- Dedicated `/audit` operations journal.
- Filtering by user, entity and action.
- Authentication and administrative mutations are written to `AuditLog`.

## SEO

- `SeoRoute` model for per-path title, description, canonical and robots flags.
- `RedirectRule` model for managed 301/302 legacy redirects.
- Public metadata resolver for homepage, products, solutions, projects and support.
- Catch-all legacy route applies enabled redirect rules without intercepting existing routes.

## Security and architecture

- Signed HttpOnly admin sessions now include role and database user identity.
- New privileged admin screens enforce role checks server-side.
- No external analytics or authentication provider is required.
