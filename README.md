# ELSYSTAR Platform

Новая web-платформа ELSYSTAR: публичный сайт, административная панель, каталог продукции, решения, проекты, документация, обращения, медиатека и собственная продуктовая аналитика.

## Текущий baseline

`v0.1.0-alpha.4 — Solutions, Projects & Homepage CMS`

### Реализовано

- лёгкая адаптивная публичная часть;
- отдельная административная панель с защищённой bootstrap-авторизацией;
- PostgreSQL + Prisma 7 data layer;
- каталог продукции и структурированные технические характеристики;
- публичные и административные разделы документации;
- заявки «Получить КП» с источником, UTM и связью с продуктом;
- медиатека с provider-neutral storage metadata;
- собственные события аналитики и dashboard;
- CMS главной страницы: hero, CTA, заголовки решений/проектов и поддержка;
- каталог решений с типами `Решение / Платформа`;
- «Мегаполис» может управляться как платформа, без отдельного жёсткого кода;
- проекты/внедрения с географией, годом, задачей, решением, результатом и связями с продукцией/решениями;
- публичные `/solutions`, `/solutions/[slug]`, `/projects`, `/projects/[slug]`;
- audit log для административных изменений.

## Структура

- `apps/web` — публичный сайт, локально `http://localhost:6300`
- `apps/admin` — административная панель, локально `http://localhost:6301`
- `packages/ui` — общий UI foundation
- `packages/database` — Prisma/PostgreSQL, схема и data runtime
- `packages/analytics` — контракты событий аналитики
- `packages/shared` — общие типы и контракты
- `docs` — архитектура и release notes

## Локальный запуск

Для просмотра без БД достаточно:

```bash
npm install
npm run db:generate
npm run dev:web
```

Во втором терминале:

```bash
npm run dev:admin
```

Для сохранения контента, заявок и аналитики нужен PostgreSQL и `DATABASE_URL`.

## Работа с БД

```bash
npm run db:generate
npm run db:push
npm run db:migrate
```

Перед использованием админки задайте `ADMIN_EMAIL`, `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET` в локальном `.env`/`.env.local`.

## Проверки

```bash
npm audit --omit=dev --audit-level=high
npm run db:generate
npm run typecheck
npm run build
```

## Принципы

- публичная часть остаётся лёгкой и быстрой;
- сложность управления переносится в отдельную админ-панель;
- нет универсального page builder, способного разрушить дизайн;
- контент хранится в типизированных сущностях;
- технические характеристики продукции структурированы;
- файлы и storage не привязаны к конкретному хостингу заранее;
- аналитика строится вокруг полезных бизнес-событий;
- публичный сайт и админка используют единую модель данных.
